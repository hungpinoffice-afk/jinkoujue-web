金口诀排盘、断课分析工具（公曆／農曆／干支輸入、月將晝夜、神煞、課鈐解讀、占斷結論、AI 斷課、五種格式導出）。

提供兩種使用方式：

| 版本 | 使用方式 |
|---|---|
| **網頁版** | 把網址傳給別人，手機／平板／電腦打開即用，不需安裝 |
| **電腦單檔離線版** | 一個 HTML 檔，雙擊開啟，完全不需要網路 |

## 電腦離線版

同層的 `知微金口诀_單檔離線電腦版.html`（約 5 MB），雙擊即可用。
程式、樣式與 1416 筆課鈐資料全部 base64 內嵌於單一檔案，可複製到隨身碟或直接傳給他人。

## 技術說明

- 純前端 React 19 + Vite 8，靜態網站，無後端。
- 課鈐資料的 `rawAll` 欄位經逐筆驗證（1416 筆、0 筆不符）可由其他欄位精確還原，
  故不重複儲存，改為執行時即時組合。
- **課鈐資料採「按需分片載入」**：資料依「日干支」切成 60 片
  （`keqian/c00.json` ～ `c59.json`，純 JSON，GitHub Pages 自動 gzip 傳輸）。
  程式每次排盤只需要當下那一課，因此首次排盤只下載 1 片（約 35KB），
  而非整個 1.5MB 資料檔。主介面不再等待資料，立即顯示。
  - 為什麼不用 `.gz`：GitHub Pages 對 `.gz` 不做傳輸壓縮，等於要下載 1.43MB 純二進位；
    改成 `.json` 後由 CDN 即時 gzip，實際傳輸只有 35KB。
  - 分片失敗會自動退回 `keqian.json.gz` → `keqian.json`。
- 導出用的 xlsx / docx / pptxgenjs 改為按下「導出」時才動態載入。
- 單檔離線版以 `format: 'iife'` + `inlineDynamicImports` 打包，
  資料以 base64 內嵌，雙擊即可在 `file://` 下執行。
- 資料載入具容錯：任何一種來源失敗，程式仍可正常排盤／斷課／神煞，
  只顯示提示橫幅（不會整頁卡死）。
- **本機儲存改為安全讀寫**：`localStorage` 在沙箱 iframe 或瀏覽器封鎖網站資料時，
  連「讀取屬性」都會拋出例外，原版會因此在首次渲染就崩潰（整頁只剩錯誤畫面）。
  現統一由 `src/utils/safeStorage.ts` 包一層，不可用時退回記憶體儲存，
  程式照常運作（僅案例／API Key 關閉頁面後不保留）。
- 排盤結果與桌面原版逐筆比對一致（2026-10-16 18:40、2024-03-15 09:30、1990-07-07 23:45 三案全部相符）。

### 關於在「預覽面板」中開啟

若在 IDE／聊天視窗的預覽面板（`sandbox="allow-scripts"`）中開啟網頁版，
沙箱會擋掉跨來源的 module 程式檔，頁面會停在標題並顯示
「程式檔載入失敗…請改用瀏覽器直接開啟」——這是執行環境限制，不是程式問題。
**單檔離線版**的程式與資料都在同一個檔案內，在預覽面板中同樣可正常運作。
